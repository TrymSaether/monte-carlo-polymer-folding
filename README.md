# Polymer folding with Monte Carlo simulation

Biophysics project in TMA4320 Introduction to Scientific Computing at NTNU (spring 2024), in Norwegian. Simulates how a polymer folds, using Monte Carlo methods.

- `polymerfolding.ipynb` and `rapport/rapport.ipynb`: the work and the report
- `polymer.py`, `assets/`: simulation code and helper functions
- `biofysikkprosjekt_2024.pdf`: the project description
